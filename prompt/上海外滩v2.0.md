使用 threejs-skills，创建一个高品质、具有真实地理空间关系的上海外滩 3D 城市景观。

**核心目标：高度还原参考图中的上海黄浦江大尺度 U 形蜿蜒河道，以及陆家嘴被河流环绕的城市空间形态。**

### 1. 地理与空间布局（最重要）
- 黄浦江必须呈现明显、连续、自然的大尺度 U 形弯曲，而不是直线河道或普通弧形滨江。
- 河道从画面左侧远处延伸，向中央区域大幅弯曲，再绕过陆家嘴区域向右侧远处延伸，形成具有包围感的马蹄形水域轮廓。
- 河流两岸自然分布城市建筑、道路、码头和滨江景观。
- 陆家嘴位于 U 形河道内侧的突出城市区域，呈现半岛般的空间视觉效果。
- 河道宽度、弯曲半径、岸线轮廓应具有真实城市地理尺度，避免规则几何弧线。
- 城市建筑沿河岸自然延伸，不能形成孤立的建筑模型集合。

### 2. 标志性建筑
重点还原陆家嘴天际线：
- 东方明珠电视塔
- 上海中心大厦
- 上海环球金融中心
- 金茂大厦

建筑集中分布在河道弯曲区域内侧，保持合理的高度比例、空间距离和地标辨识度。两岸补充密集的城市建筑群。

### 3. 场景与视觉效果
- 黄浦江采用具有真实反射效果的水面材质。
- 加入游船、货轮及其动态航行轨迹。
- 沿岸布置道路、桥梁、码头和城市灯光。
- 使用 PBR 材质、HDR 环境光、阴影和适当的 Bloom 后处理。
- 默认采用日落至蓝调时刻的光照氛围，天空呈现橙粉色与蓝灰色渐变，城市灯光逐渐亮起。

### 4. 镜头与构图
- 使用高空斜俯视的广角摄影机位，参考真实城市航拍照片。
- 镜头高度足够高，确保完整展示黄浦江 U 形弯道及两岸城市空间。
- 河道弯曲轮廓必须成为画面的核心视觉主体。
- 陆家嘴地标建筑群位于画面中央偏后位置。
- 不采用地面平视视角，不要只展示单栋建筑或局部滨江景观。

### 5. 交互与动画
- 支持鼠标旋转、缩放、平移。
- 提供自动环绕镜头展示。
- 支持白天、黄昏、夜景切换。
- 游船沿河道连续移动。
- 江面具有动态波纹和环境反射。

### 6. 技术要求
- 使用 threejs-skills 中相关 Skill。
- 使用 Three.js + WebGL，优先程序化建模。
- 采用合理的几何分段和曲线控制构建自然河岸及河道。
- 使用 CatmullRomCurve3 等曲线技术构建河流中心线和岸线，再生成连续水面网格。
- 建筑、道路、河岸、水面分别建模，保持空间关系一致。
- 优化 Draw Calls、阴影和粒子数量，保证浏览器流畅运行。

**最终验收标准：**
第一眼能够识别出上海陆家嘴和黄浦江；从整体俯视视角能够清晰看到黄浦江环绕陆家嘴的大尺度 U 形蜿蜒轮廓。河流必须具有真实自然的曲折效果，而不是一条直线或简单圆弧。
