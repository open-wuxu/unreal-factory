# 项目：上海外滩 1:1 三维数字城市建模

使用 threejs-skills，构建一个真实地理比例的上海外滩及陆家嘴 3D 数字城市场景。

## 一、核心目标

不是生成一个具有上海风格的虚拟城市，而是基于真实地理数据，重建上海外滩、黄浦江、陆家嘴及周边城市空间。

要求：
- 真实地理位置。
- 真实河道轮廓。
- 真实建筑位置和高度。
- 真实道路及城市空间布局。
- 以米为单位，采用 1:1 世界比例。

## 二、技术架构

- Three.js：精细化 3D 场景、建筑、材质、动画和交互。
- CesiumJS：地理坐标、地形、3D Tiles 和大范围空间数据管理。
- GLTF/GLB：建筑模型资源。
- GIS：真实河岸线、道路、建筑轮廓和地理坐标。
- Blender：必要时进行模型精细化和资源处理。

## 三、地理数据

首先收集上海外滩及陆家嘴区域的真实地理数据：

1. 黄浦江真实岸线及水域轮廓。
2. 城市道路、桥梁和滨江设施。
3. 建筑物地理位置、底部轮廓和高度。
4. 地形及高程数据。
5. 东方明珠、上海中心、金茂大厦、环球金融中心的精细模型。

优先采用合法授权的真实数据，不允许通过随机生成几何体替代真实地理结构。

对于无法获得的精确数据，明确标注估算值和数据来源，不得将估算数据描述为真实测绘数据。

## 四、坐标与比例

- 保留真实地理坐标。
- 统一坐标参考系统。
- 使用局部 ENU 坐标系。
- Three.js 中 1 个单位代表 1 米。
- 建筑高度、道路宽度、河道宽度采用真实尺寸。
- 解决大范围场景的浮点精度问题。

## 五、建模要求

将场景划分为：
1. 黄浦江及河岸。
2. 外滩历史建筑群。
3. 陆家嘴地标建筑群。
4. 普通城市建筑。
5. 道路、桥梁和滨江设施。
6. 水面、船舶和城市环境。

黄浦江必须根据真实岸线生成连续水域网格，保留实际弯曲、宽度变化和空间形态。

核心地标使用独立精细模型，普通建筑采用真实轮廓和高度进行程序化建模。

## 六、视觉效果

- 真实建筑材质与玻璃反射。
- 动态水面和城市灯光。
- 日落、蓝调时刻、夜景切换。
- 真实天空及环境光。
- 船舶动态航行。
- 高质量阴影与后处理。

## 七、交互功能

- 自由旋转、缩放和平移。
- 高空航拍视角。
- 城市漫游视角。
- 建筑选择及属性展示。
- 地标建筑快速定位。
- 昼夜环境切换。

## 八、开发流程

必须分阶段实施：

第一阶段：数据源调研、地理数据获取、坐标系统设计。

第二阶段：城市空间骨架和河道建模。

第三阶段：建筑模型和地标还原。

第四阶段：材质、光照和动画。

第五阶段：交互、性能优化和精度验证。

每个阶段完成后进行实际浏览器渲染验证，不要只通过代码检查判断完成。

## 九、最终交付

- 完整可运行的 Web 项目。
- 原始地理数据及处理脚本。
- 建筑模型资源及来源清单。
- 坐标转换模块。
- 场景加载和渲染模块。
- 性能优化说明。
- 地理尺寸和位置精度验收报告。

特别要求：先完成技术调研和数据可用性评估，再开始编码。如果缺少真实数据，先报告缺失项，不得用虚构数据冒充真实城市模型。
