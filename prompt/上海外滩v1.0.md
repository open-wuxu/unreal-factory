使用 threejs-skills，创建一个高质量、可交互的 Three.js 3D 城市景观场景。

**场景主题：上海外滩（The Bund, Shanghai）**

要求：
1. 还原上海外滩标志性天际线，包括东方明珠、上海中心大厦、环球金融中心、金茂大厦及黄浦江两岸建筑。
2. 构建具有真实空间层次的 3D 城市环境，建筑使用合理的几何结构、材质和灯光。
3. 设置黄浦江、江面反射、游船、道路及城市灯光。
4. 提供白天、黄昏、夜景三种时间状态切换。
5. 支持鼠标旋转、缩放、平移，以及自动环绕镜头动画。
6. 加入适量动态元素，例如游船移动、灯光变化、江面波纹。
7. 使用 PBR 材质、环境光、阴影和后处理，保证视觉质量及运行性能。
8. 优先使用程序化建模，不依赖付费模型资源；必要时可使用公开授权的 GLTF/GLB 模型。
9. 使用 threejs-skills 中相关 Skill，遵循当前 Three.js API 最佳实践。
10. 最终输出完整可运行的 Web 项目，包含启动说明。

**验收标准：** 场景具有明显的上海外滩辨识度，具有真实的 3D 空间感，交互流畅，支持桌面浏览器运行。
