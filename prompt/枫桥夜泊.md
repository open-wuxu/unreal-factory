# 任务：使用 Three.js 制作《枫桥夜泊》沉浸式三维诗词动画

## 一、作品主题

诗名：《枫桥夜泊》
作者：张继（唐）

原诗：

月落乌啼霜满天，
江枫渔火对愁眠。
姑苏城外寒山寺，
夜半钟声到客船。

使用 Three.js Skill 构建一个具有电影级视觉表现的江南古典夜景三维场景。

不要制作简单的诗词字幕动画，也不要使用平面插画代替三维场景。

目标是将古诗中的意境转化为一个真实、连贯、可漫游的三维世界，让观众仿佛置身于唐代江南的深秋夜晚。

整体风格：
- 中国古典山水美学。
- 唐代江南水乡建筑风格。
- 写实三维场景与水墨意境相结合。
- 电影级光影、雾气和景深。
- 安静、孤寂、清冷、深远的氛围。
- 以冷色调月光和暖色调渔火形成视觉对比。

## 二、视觉风格与色彩

采用深秋午夜的冷暖对比色彩体系。

主要颜色：

- 夜空：深蓝黑 `#101A2C`
- 月光：银蓝色 `#B7C9DE`
- 江水：墨蓝色 `#172A40`
- 枫叶：暗红色 `#8B302E`
- 渔火：暖橙色 `#FFAD58`
- 灯笼：暖黄色 `#E6A65A`
- 雾气：灰蓝色 `#A5B2C1`

场景整体以低亮度为主。

避免过度鲜艳的颜色、过强的霓虹光效和现代赛博朋克风格。

重点体现：
1. 月光照射下的江面反射。
2. 枫树暗红色树冠与黑色枝干的层次。
3. 江面上零星渔火的暖色倒影。
4. 远处寒山寺在薄雾中的若隐若现。
5. 深夜环境中水汽、雾气和空间纵深。

## 三、三维场景建模

构建一个完整的江南古代水乡夜景。

### 1. 天空与自然环境

- 深秋午夜天空。
- 月亮位于远山与天际线附近，呈现月落状态。
- 少量星光，不要过度密集。
- 天空具有自然的深蓝渐变。
- 远处山峦以多层低矮轮廓呈现。
- 山体被夜雾部分遮挡。
- 江面上存在低空流动的薄雾。
- 偶尔有乌鸦飞过天空。

月亮不能像白天一样明亮，整体照明应克制。

### 2. 枫桥与江岸

重点还原江南古桥与江岸环境：

- 古代石拱桥，具有真实的石材结构。
- 桥面由不规则石板组成。
- 石桥具有栏杆、桥墩和拱形结构。
- 江岸布置古代石阶、系船桩和木质码头。
- 江岸两侧种植数棵高大的枫树。
- 枫树具有丰富的枝干结构和不规则树冠。
- 枫叶采用暗红、褐红和少量橙红色。
- 部分落叶随风飘落，偶尔落在江面。

桥梁、树木和江岸必须具有真实的三维空间关系，不要将它们排列成平面背景。

### 3. 江面与客船

江面是整个场景的重要组成部分。

- 使用具有轻微波动的动态水面。
- 通过 Shader 实现水面反射和扰动。
- 月光在水面形成细长、断续的银蓝色倒影。
- 渔火在水面形成暖黄色倒影。
- 雾气贴近水面缓慢流动。
- 江面存在轻微水波和涟漪。

在画面近景设置一艘唐代风格的木质客船：

- 木船具有真实的船体结构。
- 船头、船尾、船舷、木板纹理清晰。
- 设置船篷、船舱、系船绳。
- 船只随水流轻微晃动。
- 船上有一盏微弱的灯火。
- 可以看到船舱内的诗人剪影，人物保持安静，不需要复杂的人物动画。

船只必须与水面产生真实接触，不允许悬空或穿模。

### 4. 寒山寺

在江对岸的远景中构建寒山寺。

- 唐代江南寺院建筑风格。
- 多层木质楼阁。
- 深色瓦顶、飞檐、木质柱梁。
- 寺院局部透出微弱暖黄色灯光。
- 寺院与周围山林、雾气融合。
- 建筑轮廓能够被观众辨认，但不应过于突出。
- 寺院与客船之间存在明确的空间距离。

寺院应处于远景，通过空气透视、雾气和景深表现其遥远感。

寺钟应具有独立的三维模型，置于寺院钟楼内或附近。

## 四、核心动态效果

### 1. 月落乌啼霜满天

- 月亮缓慢向地平线下降。
- 夜空保持深蓝黑色。
- 一只或几只乌鸦从远处飞过。
- 乌鸦具有自然的翅膀扇动动画。
- 江面薄雾缓慢流动。
- 远处山峦逐渐融入夜色。
- 空气中出现极其细微的霜粒或冷凝颗粒。

注意：霜满天是古诗意境表达，不应把画面做成暴雪或大面积飘雪。

### 2. 江枫渔火对愁眠

- 镜头缓慢移动到江岸枫树附近。
- 枫树枝叶受到微风影响轻微摇动。
- 少量枫叶从树枝上脱落，飘落江面。
- 江面上出现几艘远近不同的渔船。
- 渔船灯火微弱、温暖。
- 渔火倒影随着水波自然晃动。
- 镜头逐渐靠近客船。
- 展现船舱、木质结构与安静的夜景。

### 3. 姑苏城外寒山寺

- 镜头从客船视角向江对岸移动。
- 远处寒山寺逐渐从雾气中显现。
- 展示寺庙屋檐、钟楼和周围山林。
- 寺院灯火微弱。
- 镜头适度推进，突出寺院的空间纵深。
- 远处山峦和江面保持层次感。

### 4. 夜半钟声到客船

这是整段动画的情绪高潮。

- 寒山寺钟楼内的古钟缓慢摆动。
- 钟体具有真实的金属材质。
- 钟体撞击时产生细微震动。
- 使用透明环形波纹、空气扰动等视觉方式表现声音传播。
- 声波以柔和、低对比度的扩散效果从寺院方向向江面传播。
- 江面雾气产生轻微扰动。
- 客船附近水面出现微妙的波纹。
- 镜头回到客船，灯火轻轻摇曳。
- 最后停留在客船与远处寒山寺相望的画面。

声音传播的视觉效果应具有诗意，不要使用科幻雷达波或夸张的霓虹圆环。

如果可以生成音频，加入低沉、悠远、自然衰减的古寺钟声，以及轻微水声、风声和乌鸦叫声。

## 五、镜头与时间轴

制作约 40 秒的连续电影式动画。

**镜头一：月落江天（0—7秒）**

从高空远景开始，缓慢俯视江南水乡。

月亮靠近地平线，远山、江面、枫树和薄雾逐渐进入画面。

一只乌鸦掠过夜空。

字幕：

月落乌啼霜满天

**镜头二：江枫渔火（7—16秒）**

镜头缓慢下降，沿江面移动。

经过江岸枫树，观察暗红枫叶与枝干细节。

远处渔船灯火在江面上形成摇曳的倒影。

镜头继续靠近停泊的客船。

字幕：

江枫渔火对愁眠

**镜头三：寒山古寺（16—26秒）**

镜头从客船方向望向江对岸。

寒山寺在远处山雾中逐渐显现。

镜头缓慢推进，展现寺院建筑、飞檐和钟楼。

字幕：

姑苏城外寒山寺

**镜头四：夜半钟声（26—35秒）**

镜头聚焦寺院钟楼。

古钟轻轻摆动，随后撞响。

以克制的视觉方式展示声音传播，声波跨越江面，逐渐抵达客船。

字幕：

夜半钟声到客船

**镜头五：诗意收尾（35—40秒）**

镜头回到客船。

远处寒山寺隐于夜雾，江面渔火微弱，枫叶缓缓飘落。

画面逐渐拉远，最终呈现完整江南夜景。

展示完整诗名、作者和四句诗。

最后淡出。

## 六、诗词字幕设计

采用中国古典书法或宋体风格字体。

- 诗句使用优雅、克制的排版。
- 字体颜色采用暖白或浅灰白。
- 每个镜头对应一句诗。
- 诗句出现时采用淡入效果。
- 字幕不要遮挡核心三维场景。
- 最终画面完整展示诗名、作者和诗句。

字体可优先选择 Noto Serif SC、思源宋体等可用字体。

## 七、Three.js 技术要求

使用项目现有 Three.js Skill，先读取其使用说明和模块能力，再进行实现。

按需组合：

- Three.js Scene / Camera / Renderer。
- GLTF / GLB 模型加载。
- ShaderMaterial / RawShaderMaterial。
- BufferGeometry。
- InstancedMesh。
- EffectComposer。
- UnrealBloomPass。
- 自定义水面 Shader。
- 粒子系统。
- GSAP 或兼容动画时间轴。
- OrbitControls 或自定义镜头控制。

重点开发：

1. 动态水面与反射。
2. 云雾与低空薄雾。
3. 枫树及落叶动画。
4. 乌鸦飞行动画。
5. 渔火及水面倒影。
6. 古船轻微晃动。
7. 寺院钟摆与钟体震动。
8. 声波传播视觉效果。
9. 电影级镜头运动。
10. 字幕与动画时间轴同步。

复杂建筑、船只和人物可以使用合适的 GLB / glTF 模型。

对于缺少模型的部分，优先采用程序化建模补充细节。

模型应记录来源、许可和必要的修改信息。

## 八、交互功能

网页支持：

- 鼠标旋转场景。
- 滚轮缩放。
- 镜头视角重置。
- 播放、暂停、重播。
- 时间轴拖动。
- 自动演示模式。
- 天气和环境效果开关。
- 字幕显示开关。
- 音效开关。

默认进入自动演示模式，用户也可以自由探索三维场景。

## 九、性能与画面质量

- 保证水面、雾气、树木、建筑和船只的渲染质量。
- 避免过度使用高成本实时体积渲染。
- 适当采用烘焙光照、LOD 和实例化渲染。
- 优化透明物体排序。
- 控制 Bloom 强度，保证画面暗部细节。
- 支持高分辨率视频渲染。

## 十、交付要求

交付：

1. 完整 HTML 页面。
2. 完整 Three.js 项目源码。
3. 所有必要的模型、纹理及音频资源。
4. 可交互三维场景。
5. 约 40 秒完整演示视频。
6. 3840×2160 或 2560×1440 MP4。
7. 目标 60fps，记录实际导出规格。
8. 关键镜头截图。
9. 模型资源来源与许可说明。
10. 本地运行说明。

视频必须由实际三维场景逐帧渲染生成，不允许使用静态图片拼接代替动画。

## 十一、最终验收

重点检查：

- 是否真实呈现江南深秋午夜的空间环境。
- 枫树、石桥、江水、客船、寒山寺是否具有合理的空间关系。
- 水面反射是否自然。
- 渔火是否形成真实的水面倒影。
- 枫叶、雾气和乌鸦是否具有自然运动。
- 镜头运动是否连贯。
- 寺钟动画和声音传播是否同步。
- 四句诗是否与对应镜头准确匹配。
- 整体氛围是否符合原诗清冷、孤寂、悠远的意境。

优先保证场景的空间真实性、夜景光影、江水表现和镜头叙事。不要为了增加模型数量而牺牲整体意境。

最终目标：让观众仿佛乘坐一艘停泊在枫桥附近的唐代客船，在深秋午夜亲身经历《枫桥夜泊》所描绘的场景。
