## 1. 意图与由来

做一件和 `material/枫桥夜泊` 同级的作品：一个**完整可运行的 Three.js 项目**，
呈现《诛仙》中的青云门七峰 —— 不是七张山景拼图，而是一个统一坐标系下、
有真实空间关系的山脉世界：程序化侵蚀山体、漫过山谷的体积云海、
七座各有性格的主峰与山门建筑群，以及一支 36 秒的电影短片。

用户已确认：

- 交付标准为**完整交付**（场景 + 交互 + 影片 + 实际渲染 MP4 + 配乐 + 截图 + 文档）。
- 两个目录统一命名为「诛仙青云山七峰」。
- 地形采用**统一连续高度场 + 每峰参数化轮廓**。
- 云海采用**半分辨率 Ray Marching 体积云 + 地形深度遮挡**。
- 用户粘贴的提示词在「通天峰…多层屋檐」处截断，由本设计补全为完整规格。

**为什么**（从需求反推）：用户要的是「青云七峰，云海仙门」这一整体意象的
可信空间再现 —— 七峰必须同时可读（能从高空一眼数出七座）、各自可辨
（地貌、植被、建筑不同）、且能穿越（镜头进入山峰之间、穿过云层）。
因此评优标准不是模型数量，而是**空间关系、云海体积感、建筑尺度与镜头叙事**。

## 2. 目标 / 非目标 / 反目标

**目标**

- 七峰从任意高空视角可完整辨认，轮廓与高度差异明显。
- 山体是程序化侵蚀地形（脊线、沟壑、悬崖、平台），不是圆锥/规则几何。
- 云海有体积、有翻涌、有阳光轮廓光，可从云中穿行。
- 每峰有独立的建筑群与植被性格，建筑是真实三维体量而非贴片。
- 36 秒五镜头电影时间线，相机、光照、字幕、声音同步。
- 全程程序化：无外部模型、图片、音频素材。
- 完整交付：2K60 MP4、配乐、关键截图、README、REPORT。

**非目标**

- 不做人物角色动画、战斗或剧情演出。
- 不做开放世界大范围可探索内容（核心区域约 8 km × 8 km）。
- 不追求写实照片级材质；风格是「电影级东方仙侠环境概念 + 真实山岳航拍」。
- 不复刻任何现有影视/游戏的具体画面或资产。

**反目标**

- 七座山峰一个模型复制粘贴、只改缩放。
- 平面白贴图铺满山谷冒充云海。
- 建筑像积木盒、没有台基/斗拱/飞檐/栏杆的层次。
- 为了帧率砍到「低模大色块」而失去云海与山体的体积。
- 用静态图片拼接代替逐帧渲染的视频。

## 3. 约束

- 环境：Node.js ≥ 20.19（Vite 7），WebGL 2 桌面浏览器。
- 依赖：`three@0.186.0`、`vite@^7.1.0`、`playwright-core`（导出用）；
  配乐用 Python 3 + numpy/scipy。与 `material/枫桥夜泊` 保持一致。
- 坐标与尺度沿用仓库约定：X 东、Z 南、Y 上，1 单位 ≈ 1 米。
- 所有几何、贴图、环境贴图、声音由代码生成；中文排版使用系统衬线字体。
- 交付产物放 `deliverables/`；源码结构参照枫桥夜泊。
- 视频必须由真实场景逐帧渲染；导出分辨率 2560×1440、60 fps。

## 4. 方案取舍（已定）

### 4.1 地形：统一高度场 + 每峰参数化轮廓（选定）

备选：A2 七峰独立网格（山谷接缝与 LOD 过渡易穿帮）、A3 SDF/体素
（可做倒挂悬崖，但生成与渲染成本高一个量级，2K60 全片导出不现实）。

选定方案用一个**解析高度函数** `heightAt(x, z)` 贯穿全场景：

```
h = 山脚基准
  + Σ 各峰贡献（各向异性径向轮廓 + 脊线噪声 + 域扭曲 + 峰顶压平）
  + 大尺度山脊/鞍部
  + 细节噪声
  - 侵蚀沟壑
```

七峰共享同一地形，因此山谷天然连续；相机碰撞、植被落位、建筑平台、
阴影与云海遮挡都查询同一个函数/网格，不存在多套地形打架。

地形网格用**同心方环（clipmap 式）**：环 0 单元 6 m、半边长 1200 m，
每外扩一环单元边长翻倍、覆盖范围翻倍，共 6 环直至约 19 km。
所有环的顶点都取整到各级网格并共享同一函数，因此环与环的接缝严格重合。
远处环用低模，近处主峰区域足够细。

### 4.2 云海：半分辨率 Ray Marching 体积云（选定）

备选：B2 公告板粒子云（穿越镜头穿帮）、B3 混合（两套系统的接缝与遮挡
一致性成本高）。

实现为一个后处理 Pass：读取场景颜色与深度，按像素反投影出世界射线，
与云层 Slab 求交；用可平铺 3D 噪声（64³ `Data3DTexture`）做两尺度 FBM，
沿射线步进 32 步（捕获模式可调高），用场景深度提前终止并做软相交；
太阳方向做 4 步光照采样，Henyey-Greenstein 相位 + powder 项，
得到银边与暗部层次。半分辨率渲染后双线性升采样叠加。

云层分两层，共用同一个 Pass 和噪声场：

- **谷地云海（主体）**：世界 Y **740–1080 m**，密度峰值 820–950 m。
  七峰峰顶全部高于 1080 m，因此云海只吞没山脚与山谷。
- **山腰云带（稀疏）**：世界 Y **1150–1500 m**，密度约为主云海的 15%，
  仅在崖壁附近被噪声驱动出薄絮，允许擦过大竹峰（1170 m）与小竹峰
  （1330 m）的峰顶，但不形成覆盖，保证七峰始终可辨认。

### 4.3 建筑与配乐：程序化（无分叉）

沿用枫桥夜泊做法：一套共享建筑生成器（台基、柱列、斗拱、屋顶、
栏杆、石阶、匾额），七峰各自组合出不同院落；配乐用 numpy/scipy
合成箫、古琴、编钟、风与云海低频铺底。

## 5. 世界设计

### 5.1 七峰布局（坐标单位：米）

| 山峰 | 位置 (x, z) | 峰顶高度 | 基座半径 | 性格 |
| --- | --- | --- | --- | --- |
| 通天峰 | (0, 0) | 1790 | 1500 | 中央主峰，体量最大，三进主殿与百级玉阶 |
| 龙首峰 | (−200, −2900) | 1540 | 1250 | 北面长脊如龙首探向主峰，石殿、铁索栈道、碑崖 |
| 落霞峰 | (−2350, −1750) | 1270 | 1050 | 西北，西向悬崖楼阁，秋色林与石亭 |
| 风回峰 | (−3250, 250) | 1600 | 1250 | 西侧，风蚀峭壁，瀑布坠入云海，廊桥与水潭 |
| 大竹峰 | (−2000, 2600) | 1170 | 1400 | 西南，宽厚圆缓，竹海、守静堂、木栈道 |
| 小竹峰 | (1700, 2900) | 1330 | 1000 | 东南，纤细孤峰，崖边望月台与竹林 |
| 朝阳峰 | (3100, −250) | 1450 | 1300 | 东侧，东向阶梯台地，观日台与钟亭 |

**垂直基准**：谷地基准高度 **420 m**（`heightAt` 的山脚常数），
表中峰顶高度均为**绝对世界 Y**。山体相对高度因此为 750–1370 m。
峰顶设局部压平台地（通天峰约 300×260 m，其余 80–160 m）供建筑落位。

相邻峰之间保持 2.2–3.4 km 间距，山脚在鞍部相接而非合并成一个大包。
谷地云海覆盖 740–1080 m（密度峰 820–950 m），只吞山脚与山谷；
1150–1500 m 是 15% 密度的稀疏山腰云带。七个峰顶全部在云海面之上，
高空全景中至少露出峰顶与建筑台地；两峰之间以云海分隔。

### 5.2 光照与时间

影片发生在**黄金时刻向日落推进**的约 36 秒里（电影化压缩，非真实时间）：
太阳方位西偏南，高度角从约 14° 缓降至 5°，色温由琥珀转向玫红。
天空为暖色地平线 + 冷蓝天顶的渐变，高处有稀疏卷云。
方向光投影，半球光补天光；山峰西面受光、东面沉入冷影，
正好呼应「落霞峰」的命名与片尾。

### 6.2 地形构建细节

- `heightAt` 是唯一地形真值；网格、植被、建筑、碰撞都查询它。
- 每峰轮廓：`d` 经各向异性缩放与旋转 → 径向剖面
  `H * clamp(1 - d/R, 0, 1)^p`；`R` 被**角度脊线噪声**调制（山脊/冲沟），
  峰体再叠加域扭曲得到不规则山脊线。
- 峰顶平台：在台地半径内用 smoothstep 压平到指定高度，边缘留 5–8 m 过渡。
- 侵蚀：中海拔减去 `ridged^q` 沟壑，形成放射状冲沟与垂直崖壁分段。
- 顶点色按坡度/高度/朝向混合：岩壁灰褐、林地表墨绿、竹坡青绿、
  落霞峰秋林赭红、道路与台地暖灰。
- 顶点 AO：沿法线半球对高度函数采样，烘焙到顶点色/自定义属性。
- 材质：`MeshStandardMaterial` + `onBeforeCompile` 注入三平面细节贴图
  （岩壁）与世界坐标细节（草地），保留标准光照与阴影。
- 远景环降低细分，最外环没入雾与云海。

### 6.3 云海与天空

- 云 Pass 见 4.2；深度纹理由主渲染目标提供，半分辨率 RT 单独管理。
- 云层随时间沿主导风向平移（`uTime`），噪声用两尺度叠加避免团块感。
- 太阳银边：太阳方向光照采样累加，散射颜色随日落关键帧变化。
- 天空：程序化渐变穹顶 + 太阳盘与光晕 + 两层卷云（FBM 投影到穹顶），
  每帧只在光照关键帧变化时重算环境贴图。
- 雾：`FogExp2` 低密度 + 远山空气透视；云 Pass 负责谷地体积遮挡。

### 6.4 建筑与七峰场景

- `buildings.js` 生成器：须弥座台基、柱列、额枋、斗拱带、屋顶（多坡、
  起翘、脊兽、瓦垄贴图）、栏杆、石阶、牌坊、桥、亭、塔、香炉、灯笼。
  屋顶沿用「脊线 + 坡面曲率 + 四角起翘」的参数化做法。
- 七峰建筑组合（每峰至少 2–3 个可辨认体量，避免单殿孤零零）：
  - **通天峰**：山门牌坊 → 云中百级玉阶 → 广场香炉 → 玉清殿（重檐五开间）
    → 后殿与东西配殿 → 崖边钟亭。玉阶沿地形放样，带两侧望柱。
  - **龙首峰**：脊线上的石殿、铁索栈道、刻字碑崖、望云台。
  - **落霞峰**：临崖三层楼阁、秋林石亭、西向长廊。
  - **风回峰**：瀑布上方的廊桥、观瀑平台、水潭与石灯。
  - **大竹峰**：竹海中的守静堂院落、木栈道、晒药架与柴门。
  - **小竹峰**：崖边望月台（重檐亭）、小殿与竹林小径。
  - **朝阳峰**：东向阶梯台地、观日台、钟亭、石阶与山门。
- 所有建筑构件用实例化或合并几何，共享材质；贴图 Canvas 生成。

### 6.5 植被与生灵

- 竹：实例化竹竿（分段圆柱 + 竹节）+ 交叉叶片卡，顶点着色器风摆；
  大竹峰约 1.2–1.5 万竿，小竹峰约 5000–7000 竿。
- 松：递归枝干 + 实例化针叶簇，分布于岩坡与建筑周边，约 800–1200 棵。
- 秋树：落霞峰约 500–700 棵，赭红/金黄叶簇。
- 草簇与灌木：仅在建筑与路径附近约 3000 簇。
- 仙鹤：3–5 群低多边形仙鹤，振翅与滑翔动画，按固定航线穿越画面。
- 风场：所有植被共享同一 `uTime` 与方向/强度 uniform，影片中随风变化。

### 6.6 水

- 风回峰瀑布：沿崖面样条放样的水带网格，滚动噪声与泡沫 shader，
  底部水雾粒子与潭面涟漪。
- 山泉与浅溪：沿地形等高线的窄条水带（透明、菲涅尔、慢速流动）。
- 水潭：小面积 `Reflector` + 自定义着色，反射天空与山体轮廓。
- 水面颜色与亮度随日落关键帧变化。

### 6.7 渲染、后处理与性能

- `WebGLRenderer`，ACES Filmic tone mapping，像素比上限 1.6，
  MSAA 4× 半浮点主 RT；WebGL 2 不可用时显示回退提示。
- 后处理链：`RenderPass → CloudPass（半分辨率）→ UnrealBloomPass
  → GradePass（冷暖分离、暗角、轻颗粒）→ OutputPass`。
- 阴影：单方向光，4096² PCF。阴影相机**跟随当前镜头/视角的注视点**，
  覆盖约 3 km 见方（≈0.7 m/texel），保证近景斗拱、栏杆与玉阶的投影清晰；
  远景山峰不依赖实时阴影，改用烘焙顶点 AO 与坡向明暗。
  `autoUpdate = false`，捕获模式每帧、实时模式每 0.5 秒刷新，焦点移动时立即刷新。
- 实例化：竹、树、栏杆、斗拱、瓦当等重复构件全部 `InstancedMesh`。
- 远景地形与远山低模；云半分辨率；避免 CPU 每帧重建几何。
- 目标：M 系列/RTX 级桌面在 1440p 下 ≥ 30 fps（云端 Pass 可降步数），
  捕获导出允许逐帧慢渲。

### 6.8 相机、交互与影片

- `OrbitControls` 自由视角；点击预设机位缓动飞行；`1–7` 切七峰，
  `8` 全景，`Space` 播放/暂停，`R` 重置。
- 底部时间轴可拖动；拖动或鼠标操作进入自由探索；「观看影片」进入
  `?film=1` 纯净页；`?capture=1` 关闭实时循环。
- 开关：云海、雾、字幕、声音。
- 影片 36 秒、60 fps，**五镜头电影剪辑**。每个镜头使用独立的
  Catmull-Rom 机位曲线（位置与注视点分别插值），镜头之间不做连续飞行；
  转场方式为**穿云/穿雾转场**：在切点前 0.6–0.9 秒让云层或雾带充满画面，
  黑场/云色遮罩达到峰值时切换到下一镜头，随后重新显影。这样既跨得过
  3–4 km 的地理距离，又保留「穿过云层进入下一峰」的连贯感。
  时间轴、字幕与声音都以绝对时间驱动，可任意拖动。五镜头：

| 时间 | 镜头 | 内容 | 字幕 |
| --- | --- | --- | --- |
| 0–8 s | 云海初开 | 高空全景，七峰自云海浮出，霞光染边 | 云海初开，七峰浮青 |
| 8–15 s | 通天玉阶 | 穿过云带逼近主峰，沿百级玉阶升至玉清殿 | 通天一径，玉阶凌云 |
| 15–22 s | 竹影双峰 | 贴竹海滑行，掠过山门，小竹峰崖亭迎面而来 | 竹影摇风，双峰对望 |
| 22–29 s | 龙首垂瀑 | 谷中仰视风回峰瀑布，镜头升起越过龙首脊线 | 龙首垂瀑，风回千仞 |
| 29–36 s | 落霞满袖 | 落霞峰逆光楼阁，拉远至七峰全景，片名淡出 | 落霞满袖，青云不老 |

- 末尾 1.5 秒淡出并显示片名「青云七峰 · 云海仙门」。
- 每条镜头曲线内部用 Catmull-Rom（位置与注视点分别插值），保证单镜头内
  起落速度连续；镜头之间由云色遮罩转场连接，不追求跨镜头的路径连续。
- 光照关键帧：太阳高度/方位、色温、曝光、雾色、云散射颜色随时间插值。
- 字幕与片名在 `index.html` 中，`film.js` 按绝对时间控制透明度。

### 6.9 导出与配乐

沿用枫桥夜泊的全套管线：

1. `npm run dev -- --port 5188 --strictPort`
2. `npm run export:film -- --frames deliverables/frames`（2560×1440，60 fps，
   2160 帧，`?film=1&capture=1`，固定步长与固定随机种子）。
3. `npm run encode:film` 编码无声 MP4；`npm run stills:film` 截关键帧。
4. `npm run score` 用 numpy/scipy 合成 36 秒配乐：
   箫/笛主题、古琴拨弦、低频云海铺底、风与瀑布环境、远处编钟。
   统一响度 -18 LUFS，封装 AAC 音轨。
5. `deliverables/REPORT.md` 记录分辨率、帧率、时长、码率、响度、
   渲染耗时与截图。

## 8. 验收

- `npm run build` 通过；`npm run dev` 可在浏览器打开。
- 高空全景中七峰可数清、可辨认；任意相邻两峰之间有明显鞍部/深谷。
- 山体近景能看到脊线、沟壑、崖壁与分层植被，不是光滑锥体。
- 云海有厚度、有流动、有受光银边；相机可从云中穿过且不穿帮。
- 通天峰主殿群有台基、柱列、斗拱、重檐、栏杆、石阶等层次。
- 36 秒影片镜头连贯，五个字幕与画面匹配，片尾完整显示片名。
- 导出 2560×1440 / 60 fps / 36 s MP4，音轨响度达标；关键截图齐全。
- 无外部模型/图片/音频；README 与 REPORT 完整。
