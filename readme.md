# unreal_factory

外滩（The Bund）三维场景的原型与素材仓库。

当前收录两个**完全程序化生成、可交互**的 Three.js 城市景观版本，全部几何、贴图与
环境贴图均由代码或 Canvas 生成，不依赖外部模型、图片或付费资源；可作为场景搭建、
镜头与材质效果的参考素材。

## 目录结构

```
unreal_factory/
├── material/
│   ├── 上海外滩v1.0/     # 直线河道版本（存档）
│   └── 上海外滩v2.0/     # U 形江湾 + 陆家嘴半岛版本（当前主版本）
├── .gitignore
└── readme.md
```

两个版本是**相互独立的前端项目**，各自带有 `package.json` 与 `.gitignore`，
可以单独安装、运行与构建。

详细差异与实现说明见各版本 README：

- [上海外滩 v1.0](./material/上海外滩v1.0/README.md)

## 快速开始

环境要求：Node.js ≥ 20.19，支持 WebGL 2 的桌面浏览器。

```bash
cd material/上海外滩v2.0

npm install
npm run dev
```

打开终端提示的地址（默认 <http://localhost:5173>）。

生产构建与本地预览：

```bash
npm run build
npm run preview
```

构建产物输出到 `dist/`，使用相对路径，可部署到任意静态服务器或子目录。

## 场景亮点

- **四座地标**：东方明珠、上海中心、环球金融中心、金茂大厦，均为参数化建模。
- **外滩建筑群**：16 栋历史建筑，含柱廊、山花、穹顶、绿色铜皮屋顶与海关钟楼。
- **黄浦江水面**：真实平面反射 + 自定义水面着色器，含菲涅尔、波光、夜间灯影与贴岸泡沫。
- **昼夜系统**：白天 / 黄昏 / 夜景三种状态，1.9 秒平滑过渡，天空、灯光、雾、
  曝光、泛光与窗灯统一插值。
- **城市动态**：车流、游船、货轮、桥梁缆索与码头灯光。
- **性能优化**：`InstancedMesh`、共享材质、像素比上限 1.6。

## 开发约定

- 每个版本目录自成一体，依赖与构建脚本互不影响。
- `node_modules/`、`dist/` 等生成物不入库，由各目录的 `.gitignore` 统一忽略。
- 本机 skills 配置（`.claude/`、`.agents/`、`skills-lock.json`）不入库，见根目录 `.gitignore`。
